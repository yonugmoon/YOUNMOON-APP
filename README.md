# kt MOS-APP
정보통신설비

## 정보통신설비 실위치 (`정보통신설비_실위치.html`)
각 층 피난안내도(평면도)를 촬영해 반듯하게 펴고, 정보통신 설비실 위치를 층별로 표시·관리하는 단일 HTML 앱 (외부 라이브러리 없음, 오프라인 동작).

- **스캐너**: 카메라 화면에서 안내도 테두리 실시간 자동 검출, 자동 촬영, 조명(토치)
- **영역 지정**: 드래그 박스로 도면 영역 선택(안내도 원근에 맞춰 정렬, 변·모서리 크기 조절, 가운데 손잡이 이동), 필요 시 꼭짓점 4점 조정
- **수평·수직 자동 보정**: 원근(키스톤) + 잔여 기울기 자동 보정 (선택 영역 자르기 / 사진 전체 유지)
- **필터**: 선명 컬러(조명 평탄화) · 원본 · 흑백 · 문서 스캔
- **실 위치 표시**: MDF·IDF·TPS·EPS·통신실·전산실·방재실·전기실·기계실, 직접입력, 메모 / 번호·비고, 이동·크기·삭제·실행취소, 핀치 줌
- **층 관리**: 건물·층별 목록, 동일층 추가(`3-7, 9, B1` 같은 평면 층에 평면도·실 위치 일괄 복사), 층 전환 바(자동 저장)
- **저장·공유**: 기기 내 저장(IndexedDB), 층 배지·실 목록이 포함된 이미지 공유/다운로드
