# kt MOS-APP
정보통신설비

## RepiQ 현장수집 · 디지털트윈 (`RepiQ_현장수집.html`)
도면·설비 사진 → AI 판독 → 설비대장 현행화 → **디지털트윈**

- **트윈 동기화 지수**: 현장일치·도면배치·계통연결·사진증빙·판독신뢰를 합친 0~100 점수, 마지막 현행화 후 경과일 표시
- **건물 모델**: 층(B2·1F·RF 등)별 설비 수와 상태 분포를 단면 형태로 표시
- **평면 배치**: 도면 위에 설비 핀 표시. AI가 좌표를 추출하고, 사람이 탭해서 재배치 가능
- **계통·영향 분석**: MDF→IDF→세대단자함, UPS→PDU 같은 계통을 규칙으로 추론(직접 지정도 가능)하고, 장애 시 영향받는 하위 설비 수 표시
- **현행화 이력**: 설비마다 고유 ID를 두어 재연동해도 핀·계통·현장확인 정보 유지, 변경분(추가/삭제/변경) 기록
- **내보내기**: CSV(층·상위설비·좌표·현장확인 포함), 트윈 JSON(건물·자산·연결선·이력)

## ICT Twin v2.0 · 2D/3D 디지털트윈 관제 (`ICT_Twin.html`)
- **구성관계 그래프(asset_relation)**: 전원/통신/접지/경로 관계를 데이터로 정의 → 장애 파급 BFS(중단·잠재위험), 토폴로지 SVG, 3D 계통 아크 자동 생성
- **노후도 규칙엔진(100점)**: 사용연수30·단종20·고장이력20·부품수급10·계측저하10·중요도10(하위 의존도). 연도 시뮬레이션·계측 반영 시 자동 재산정, 산출 근거 표시
- **3D 고도화**: 돌하우스에 실제 자산 위험도 기둥·장애 펄스·접지/열화상 오버레이, 선택 시 카메라 fly-to, 터치·핀치 조작, WASD 1인칭 워크스루, 실평면 미니맵(클릭 이동), 재구성 시 GPU 메모리 해제
- **실시간 관제**: 텔레메트리 스트림(센서 미연동 시 시뮬레이션) + 알람 콘솔(히스테리시스·확인 처리), ΔT 추이 스파크라인. 실데이터는 `ICTTwin.ingest({assetId, thermalDt, rackTemp, groundingOhm, opticalRx})`
- **영속화**: 계측·OCR 검수·견적 선택·알람 확인 상태 자동 저장, 스냅샷 JSON 내보내기/복원

## ICT Twin ADMIN 6 · 2D/3D 통합 디지털트윈 (`ICT_Twin_ADMIN_6.html`)
ADMIN_5(정보통신설비 DB·디지털 트윈·측정 통합)에 **TwinX 전체화면 2D/3D 통합 뷰어**를 레이어 방식으로 접목한 판.
- 진입: 「디지털 트윈」 화면의 **🧊 2D·3D 통합 뷰어** 버튼, 또는 어디서나 `Shift+T`
- 도면 뷰포트가 화면의 약 89~93% (툴바 52px·상태바 28px, 층 레일·인스펙터·범례는 도면 위에 뜨는 접이식 패널)
- 보기: 2D CAD / 3D / 분할 · 3D 시안 A(돌하우스 적층)·B(룸·랙 투시)·C(홀로그램 계통)·D(열화상·위험기둥)
- 데이터: ADMIN에 등록된 실·설비·연결·정기점검 실측을 읽기 전용으로 사용 (센서 자동 수집 아님)
- 현행화 도구(툴바 「현행화 ▾」): **측정 매칭 확인**(측정 업로드 시 알림 → 위치 그룹별 설비ID/실 자동 매칭 결과 검토·수동 지정·추정 승인·제외, 설비ID 매핑표 CSV), **구조 편집**(2D 도면에서 문 위치·폭/문 없음, 케이블 트레이 경로 그리기(직각·끝점 스냅), EPS 라이저 위치·관통 층 등록 → 추정값 대체), 인스펙터 「랙 · U」 **편집**(랙 이름·규격·시작/끝 U, 입면 미리보기·중복 경고), 툴바 **도면 배경**(층별 CAD 평면도 PNG/JPG를 2D·3D에 겹쳐 보기, 2점 맞춤·투명도·반전). 입력값은 이 브라우저에 저장되며 랙 입력은 JSON 내보내기/가져오기 지원
- 소스: `twin-admin/` (팀별 모듈 `src/`, 계약서 `CONTRACT.md`, 빌드 `python3 twin-admin/build.py`, 시험 `test/`)

### 간이 현행화 모드 (현장 자료만으로 트윈 만들기)
툴바 「현행화 ▾ → 간이 현행화 모드」. 설비 현행화표(설비명·규격·수량·제조사·설치위치·설치연도·비고)와 대피소/종이 도면 사진만 있으면 됩니다.
1. 현행화표 붙여넣기(엑셀에서 복사) → 2. 도면 사진 + 치수 2점으로 축척 맞춤 → 3. 실 그리기 → 4. 설비 클릭 배치 → 5. 자동 연결·점검·엑셀 내보내기.
내보낸 `ICT_Twin_Quick_YYYYMMDD.xlsx`를 데이터 관리 → 엑셀 등록 → 「전체 교체 적용」, 점검 결과서는 측정 엑셀 등록 + 측정 매칭 확인으로 연결합니다.
초안은 이 브라우저에만 저장되므로 다른 PC로 옮길 때는 JSON 백업을 사용하세요.

### 디지털트윈 제작 파이프라인 (사진 조사 · PDF 도면 · 자동 작도 · 점검 결과서 연계)
- 표준 문서: [`docs/DigitalTwin_Production_Standard.md`](docs/DigitalTwin_Production_Standard.md) — 상위 목표 · 입력 데이터 · 제약 조건 · 출력 포맷 · 단계별 검증
- 간이 현행화 모드에서 설비별 📷(전경·명판·모듈) 촬영, PDF 도면 올리기, 도면이 없으면 「자동 작도」, ⑤에서 층간 연결·라이저도·개통도·사진 ZIP
- 「현행화 ▾ → 점검 결과서 변환」: 엑셀·워드·PDF 결과서 → 측정 엑셀(설비ID 연결) → 「ADMIN 측정 등록으로 보내기」

### ADMIN 화면 ↔ 2D·3D 뷰어 융합
「디지털 트윈」 화면 상단 탭 **4. 입체 트윈**: 별도 전체화면 없이 도면 자리에서 2D CAD·3D·분할을 보고, 「토폴로지 나란히」로 ADMIN 토폴로지와 3D를 한 화면에 표시. 층 선택·설비 선택·우측 상세 패널이 서로 연동되며 「⛶ 크게」로 기존 전체화면 뷰어 전환.

### 설비 묶음 · 구조 편집 개선 · 현행화 완료
- **묶음**: 같은 층·같은 위치의 같은 장비(모듈 여러 개)를 1개 랙으로 2D·3D에 배치, 설비 상세 「묶음 슬롯」에서 모듈별 상태. 설비 상세 「묶음으로」 또는 간이 현행화 「수량 2대 이상은 묶음」. ADMIN 규격 `[묶음:이름]` 태그로 보존.
- **구조 편집**: 「문 위치 지정」「트레이 그리기」「라이저 위치 지정」 버튼으로 시작, 도면 위 「✔ 경로 완료 / ✖ 취소」, 하단 저장 시각 · 「편집 완료」.
- **간이 현행화 완료**: 단계별 ✔, 「✔ 현행화 완료 · 저장」 → 「ADMIN에 등록(적용)하기」.

### 꿈꾸기(Dreaming) 현행화 점검 · 4층 기억 구조
「현행화 ▾ → 꿈꾸기 현행화 점검」: 자료가 바뀌면 자동으로 원본(측정·이력·연결)과 DB를 대조해 불일치 교정 제안(상태-실측 불일치, 교체주기 초과, 미점검, 끊긴 연결, 고립 설비, 랙 U 중복, 측정 미매칭), 설비별 변경 노트, 고위험만 승격한 4층 핵심 요약(MEMORY.md, 200줄 이내), 위험도 가중치 1개 국소 보정(수정 전후 비교 · 승인 시 적용). 보고서 엑셀·MEMORY.md 저장.

### 데이터 관리 센터 · 계통도 · 좌표 정합 (구조 정리)
- **데이터 관리 센터**(현행화 ▾ 맨 위): 층별 출처(시범/사용자 등록) 확인, 복원용 백업·복원, ① 시범 데이터 제거 ② 선택 층 공간·설비 새로 작성(도면 유지) ③ 선택 층 배치만 초기화(미배치 설비로 관리) ④ 전체 초기화. 실행 전 대상 개수 표시 + 백업 자동 저장, ADMIN 확인창 경유. 초기화 후 새로고침해도 시범 자료가 다시 생기지 않음.
- **계통도 보기**(2D | 3D | 분할 | 계통도): 도면 없이 설비·묶음·연결만. 노드 끌기는 화면 배치만(설치 위치 영향 없음), 선택은 2D·3D·상세와 공유, 연결 추가·삭제 → ADMIN 반영.
- **좌표 정합**: 간이 현행화 「ADMIN 층 불러와 편집」 → ② 「기존 실·설비를 도면에 맞추기(4점)」 → 등록 시 그 층만 교체(다른 층 유지).
- 라벨은 기본 간단 표시(레이어 「설비 상세 라벨」), 상태 색은 측정 판정 반영 기본 · 「ADMIN 상태 기준 색」으로 ADMIN 화면과 동일하게.

## ICT Twin 단독 운영판 (`ICT_Twin_Standalone.html`)
ADMIN 없이 단독으로 운영·시험하는 단일 HTML (오프라인). 빌드: `python3 twin-admin/build_standalone.py`
1. **자료 등록** — 설비 엑셀(`docs/ICT_Twin_Equipment_Form.xlsx` 양식: No·장비명·설비구분(34종)·모델명·제조사·수량·위치) 「엑셀 파일 올리기」 → 「같은 랙 설비인가요?」 묶음 선택. 점검 결과서(워드·PDF·엑셀)는 「현행화 ▾ → 점검 결과서 변환 → 트윈에 결과 적용」.
2. **도면 등록·실·선로** — 도면(사진·PDF) → 축척 맞춤 → 실 그리기(위치 이름과 같은 실을 그리면 설비 자동 배치) → 계통도에서 선로(연결) 추가 · 구조 편집으로 트레이.
3. **연동 표시** — 같은 자료가 2D CAD · 3D · 계통도 · 설비 상세(묶음 슬롯·측정값)에 반영, 측정 판정으로 상태 색.
저장: 이 PC 브라우저 자동 저장 + 「현행화 ▾ → 백업 저장(도면 포함)」.
