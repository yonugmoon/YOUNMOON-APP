# kt MOS-APP
정보통신설비

## RepiQ 현장수집 · 디지털트윈 (`RepiQ_현장수집.html`)
도면·설비 사진 → AI 판독 → 설비대장 현행화 → **디지털트윈**

- **트윈 동기화 지수**: 현장일치·도면배치·계통연결·사진증빙·판독신뢰를 합친 0~100 점수, 마지막 현행화 후 경과일 표시
- **건물 모델**: 층(B2·1F·RF 등)별 설비 수와 상태 분포를 단면 형태로 표시
- **평면 배치**: 도면 위에 설비 핀 표시. AI가 좌표를 추출하고, 사람이 탭해서 재배치 가능
- **계통·영향 분석**: MDF→IDF→세대단자함, UPS→PDU 같은 계통을 규칙으로 추론(직접 지정도 가능)하고, 장애 시 영향받는 하위 설비 수 표시
- **현행화 이력**: 설비마다 고유 ID를 두어 재연동해도 핀·계통·현장확인 정보 유지, 변경분(추가/삭제/변경) 기록
- **내보내기**: CSV(층·상위설비·좌표·현장확인 포함), 트윈 JSON(건물·자산·연결선·이력)

## ICT Twin v2.0 · 2D/3D 디지털트윈 관제 (`ICT_Twin.html`)
- **구성관계 그래프(asset_relation)**: 전원/통신/접지/경로 관계를 데이터로 정의 → 장애 파급 BFS(중단·잠재위험), 토폴로지 SVG, 3D 계통 아크 자동 생성
- **노후도 규칙엔진(100점)**: 사용연수30·단종20·고장이력20·부품수급10·계측저하10·중요도10(하위 의존도). 연도 시뮬레이션·계측 반영 시 자동 재산정, 산출 근거 표시
- **3D 고도화**: 돌하우스에 실제 자산 위험도 기둥·장애 펄스·접지/열화상 오버레이, 선택 시 카메라 fly-to, 터치·핀치 조작, WASD 1인칭 워크스루, 실평면 미니맵(클릭 이동), 재구성 시 GPU 메모리 해제
- **실시간 관제**: 텔레메트리 스트림(센서 미연동 시 시뮬레이션) + 알람 콘솔(히스테리시스·확인 처리), ΔT 추이 스파크라인. 실데이터는 `ICTTwin.ingest({assetId, thermalDt, rackTemp, groundingOhm, opticalRx})`
- **영속화**: 계측·OCR 검수·견적 선택·알람 확인 상태 자동 저장, 스냅샷 JSON 내보내기/복원

## ICT Twin ADMIN 6 · 2D/3D 통합 디지털트윈 (`ICT_Twin_ADMIN_6.html`)
ADMIN_5(정보통신설비 DB·디지털 트윈·측정 통합)에 **TwinX 전체화면 2D/3D 통합 뷰어**를 레이어 방식으로 접목한 판.
- 진입: 「디지털 트윈」 화면의 **🧊 2D·3D 통합 뷰어** 버튼, 또는 어디서나 `Shift+T`
- 도면 뷰포트가 화면의 약 89~93% (툴바 52px·상태바 28px, 층 레일·인스펙터·범례는 도면 위에 뜨는 접이식 패널)
- 보기: 2D CAD / 3D / 분할 · 3D 시안 A(돌하우스 적층)·B(룸·랙 투시)·C(홀로그램 계통)·D(열화상·위험기둥)
- 데이터: ADMIN에 등록된 실·설비·연결·정기점검 실측을 읽기 전용으로 사용 (센서 자동 수집 아님)
- 현행화 도구(툴바 「현행화 ▾」): **측정 매칭 확인**(측정 업로드 시 알림 → 위치 그룹별 설비ID/실 자동 매칭 결과 검토·수동 지정·추정 승인·제외, 설비ID 매핑표 CSV), **구조 편집**(2D 도면에서 문 위치·폭/문 없음, 케이블 트레이 경로 그리기(직각·끝점 스냅), EPS 라이저 위치·관통 층 등록 → 추정값 대체), 인스펙터 「랙 · U」 **편집**(랙 이름·규격·시작/끝 U, 입면 미리보기·중복 경고), 툴바 **도면 배경**(층별 CAD 평면도 PNG/JPG를 2D·3D에 겹쳐 보기, 2점 맞춤·투명도·반전). 입력값은 이 브라우저에 저장되며 랙 입력은 JSON 내보내기/가져오기 지원
- 소스: `twin-admin/` (팀별 모듈 `src/`, 계약서 `CONTRACT.md`, 빌드 `python3 twin-admin/build.py`, 시험 `test/`)
