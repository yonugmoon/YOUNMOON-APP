# kt MOS-APP
정보통신설비

## 피난안내도 스캐너 (`피난안내도_스캐너.html`)
벽에 붙은 피난안내도를 촬영해 바로 현재 위치를 표시하는 단일 HTML 앱 (외부 라이브러리 없음, 오프라인 동작).

- **스캐너**: 카메라 화면에서 안내도 테두리를 실시간 자동 검출, 자동 촬영, 조명(토치), 모서리 4점 수동 조정(확대경)
- **수평·수직 자동 보정**: 원근(키스톤) 보정 + 잔여 기울기 자동 측정·보정, 촬영 중 기기 수평계 표시
  - `스캔` 모드: 안내도 영역만 잘라 반듯하게 펴기 / `수평·수직 보정만` 모드: 사진 전체 유지
- **필터**: 선명 컬러(조명 평탄화) · 원본 · 흑백 · 문서 스캔
- **위치 표시**: 현위치(방향 표시 가능), 비상구, 계단, 소화기, 집결지, 대피경로(그리기), 메모 / 이동·크기·삭제·실행취소, 핀치 줌
- **저장·공유**: 기기 내 저장(IndexedDB), 표시가 합성된 이미지 공유/다운로드
